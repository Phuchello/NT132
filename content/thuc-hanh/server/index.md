# Lab Server

Nhóm thực hành này tập trung vào **dịch vụ đang chạy ở đâu, lắng nghe trên interface/port nào và client có truy cập được hay không**.

## Bạn cần làm được

- Kiểm tra IP, gateway, DNS và trạng thái network interface của server.
- Xác định service/process đang chạy và port đang listen.
- Phân biệt lỗi service với lỗi firewall, routing, name resolution hoặc quyền truy cập.
- Verify từ cả phía server và phía client thay vì chỉ nhìn trạng thái service local.
