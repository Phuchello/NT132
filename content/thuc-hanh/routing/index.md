# Lab Routing

Nhóm thực hành này tập trung vào **route table → quyết định next-hop → kiểm tra đường đi thực tế**.

## Bạn cần làm được

- Đọc và giải thích các route `connected`, `static` và route học từ routing protocol.
- Kiểm tra next-hop/interface mà router chọn cho một destination cụ thể.
- Dùng `ping`, `traceroute`/`tracert` và lệnh kiểm tra routing table để xác định điểm lỗi.
- Phân biệt lỗi cấu hình route với lỗi interface, IP addressing hoặc reachability ở lớp dưới.
