# Lab Administration

Nhóm thực hành này tập trung vào **thay đổi cấu hình có kiểm soát và xác minh trạng thái hệ thống sau thay đổi**.

## Bạn cần làm được

- Quản lý user/group và kiểm tra quyền sau khi cấu hình.
- Kiểm tra, start/stop/restart service và đọc trạng thái/log liên quan.
- Cấu hình network cơ bản rồi verify IP, route, DNS và connectivity.
- Chẩn đoán theo chuỗi **symptom → state → command kiểm tra → nguyên nhân** thay vì thử lệnh ngẫu nhiên.
